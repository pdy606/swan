# 2026-11-02 로컬 LLM 오프라인 기록

실행: Mac M4 Pro, RAM 24GiB, Ollama 0.33.3, 설치된 Q4_K_M 모델. 종료 시각은 `summary.json`에 기록했다. ROS나 Gazebo를 새로 실행하지 않았고 주행 명령을 발행하지 않았다.

| 검사 | 요청 | 기준과 일치 | 지연 중앙값 |
|---|---:|---|---|
| Qwen 3 8B, 센서 텍스트 | 24 | 기대 행동 18/24 | 전체 2.158초, 첫 요청 9.286초 |
| Gemma 3 4B, 센서 텍스트 | 24 | 기대 행동 12/24 | 전체 1.641초, 첫 요청 4.319초 |
| Gemma 3 4B, 원본 이미지 | 18 | 색상 12/18, 색상과 조언 동시 일치 9/18 | 각 이미지 첫 투입 5.124초, 동일 이미지 재투입 1.353초 |

총 66회 모두 JSON 형식은 준수했지만, 두 모델 모두 전방 0.6m 사례에서 `forward`를 3/3회 제안했다. Gemma는 신호 없는 장면을 초록으로 3/3회 답했다. 실제 주행에는 연결하지 않았다.

센서 8사례, 이미지 6장을 각각 3회 반복했다. 센서 1사례는 10/8 기록의 수치와 가정한 센서 나이를 사용했고 나머지 7사례는 가정 입력이다. 이미지에는 인위적인 적색/청색 walking 도형과 잘린 신호가 포함된다. 잘린 신호의 `unknown`은 판단 유보 규칙이다. 이 수치를 일반 정확도, 독립 반복 성공률 또는 자율주행 성공률로 사용하지 않는다.

- [실행 가이드](../LOCAL_LLM_GUIDE.md)
- [재현 도구](../../../tools/local_llm/run_offline_check.py), [입력과 이미지](../../../tools/local_llm/fixtures/)
- `trial_config.json`: 당시 프롬프트, Schema, 설정.
- `results.jsonl`: 요청별 답변과 지연. 원본 기록에서 로컬 `response_file` 참조만 제거한 공유용 사본이다.
- `summary.json`: 사례별 집계, 초기 요청과 반복 요청 구분, 한계와 소스 확인 결과.

재현 도구는 같은 프롬프트와 입력을 사용하지만 모델 태그, 장비, 부하와 캐시 상태에 따라 결과가 달라질 수 있다. 최신 전체 ROS 스택 동시 실행 부하와 거리/Gap 정확도는 이 기록의 검증 범위가 아니다.
