11/2에는 VM·Gazebo·YOLO를 실행하지 않았다. 아래는 소스와 기존 실행 기록을 대조한 안내이며 최신 전체 조합·새 PC 설치의 실행 검증 완료를 의미하지 않는다.

1. 처음 한 번 — 새 작업 폴더 받기

ROS Jazzy와 Gazebo Harmonic이 설치된 데스크톱에서 실행한다.
기존 미커밋 작업 폴더는 보존하고 새 폴더에 받는다. ~/swan_seunghyun_ws가 이미 있다면 다른 새 이름을 사용하고 아래 경로도 맞춘다.

sudo apt update
sudo apt install -y git python3-venv python3-colcon-common-extensions \
  python3-gz-transport13 ros-jazzy-ros-gz ros-jazzy-tf2-ros \
  ros-jazzy-image-tools ros-jazzy-cv-bridge ros-jazzy-teleop-twist-keyboard

git clone --branch seunghyun --single-branch https://github.com/pdy606/swan.git ~/swan_seunghyun_ws
cd ~/swan_seunghyun_ws
source /opt/ros/jazzy/setup.bash
rosdep install --from-paths src/swan_world_integration --ignore-src -r -y
colcon build --symlink-install --packages-select swan_world_integration

rosdep 초기 설정이 되어 있어야 한다. python3-gz-transport13이 없으면 Harmonic apt 저장소 설정을 확인한다.
아래 두 실행 방식 중 하나만 사용한다. 동시에 켜면 Gazebo·로봇·같은 토픽이 중복된다.

2. 기존 연결 동선 확인용 — 터미널 A

source /opt/ros/jazzy/setup.bash
source ~/swan_seunghyun_ws/install/setup.bash
ros2 launch swan_world_integration recording.launch.py start_zone:=apartment moving_traffic:=false

월드·고정 버전 휠체어·카메라 창·카메라/LiDAR 브리지를 연다. 로봇 정착 후 조작한다.
이 명령은 자동 경로 주행기가 아니다. 전체 180.6m 자동 주행이나 최신 Vision·Nav2·안전 제어를 시작하지 않는다.
출발 구역: start_zone:=apartment / market / city
시장 이동 교통·신호 전환: moving_traffic:=true
렌더링 문제: 기존 실행 종료 후 software_rendering:=true 추가
카메라 창 생략: show_camera:=false

터미널 B — 키보드 운전

source /opt/ros/jazzy/setup.bash
source ~/swan_seunghyun_ws/install/setup.bash
ros2 run teleop_twist_keyboard teleop_twist_keyboard --ros-args \
  -r cmd_vel:=/model/wheelchair/cmd_vel \
  -p speed:=0.15 -p turn:=0.3 -p repeat_rate:=10.0 -p key_timeout:=0.2

운전 터미널에 포커스를 두고 i 전진 / , 후진 / j·l 회전 / k 정지.
종료: B에서 k → Ctrl+C, A에서 Ctrl+C. 각각 프롬프트가 돌아온 뒤 재실행한다.

3. 선택 — 촬영 월드에 최신 YOLO만 별도로 연결

최신 YOLO 실행·거리 정확도는 미검증이다. 아래 설치 예시는 기존 10/18 검사에 사용한 Python 의존성 버전이며 최신 모델 호환성도 재확인이 필요하다.

/usr/bin/python3 -m venv --system-site-packages ~/venvs/swan-yolo
source ~/venvs/swan-yolo/bin/activate
python -m pip install 'numpy<2' 'opencv-python<4.12' 'ultralytics==8.4.127'
deactivate

cd ~/swan_seunghyun_ws
source /opt/ros/jazzy/setup.bash
colcon build --symlink-install --packages-select wheelchair_vision

터미널 C:
source /opt/ros/jazzy/setup.bash
source ~/swan_seunghyun_ws/install/setup.bash
source ~/venvs/swan-yolo/bin/activate
python -m wheelchair_vision.yolo_node

터미널 D:
source /opt/ros/jazzy/setup.bash
source ~/swan_seunghyun_ws/install/setup.bash
ros2 run image_tools showimage --ros-args -r image:=/yolo/image_raw

best.pt가 설치 경로에서 로드되는지 확인한다. no detections는 그 프레임에서 임계값 이상의 검출이 없다는 뜻이다.
원본 창과 YOLO 결과 창은 별개다. 거리값 출력은 실제 거리 정확도 보장이 아니다.
추가 종료: 먼저 운전을 정지하고 D·C 각각 Ctrl+C, B·A도 위 순서대로 종료한다.
시스템 ros2 run으로 YOLO를 실행하면 가상환경 Python을 사용하지 않을 수 있어 C에서는 가상환경 python을 직접 쓴다.

4. 최신 팀 전체 스택

전체 ROS/Python 의존성이 준비된 작업공간에서 실행한다.

cd ~/swan_seunghyun_ws
source /opt/ros/jazzy/setup.bash
rosdep install --from-paths src/swan_bringup src/swan_pipeline src/wheelchair_gazebo \
  src/wheelchair_navigation src/wheelchair_vision src/swan_interfaces --ignore-src -r -y
colcon build --symlink-install --packages-up-to swan_bringup
source install/setup.bash
ros2 launch swan_bringup swan.launch.py

wheelchair_world.sdf와 최신 로봇·Vision·상황 판단·주행·영상 창을 함께 시작한다. Ctrl+C 후 프롬프트 복귀를 확인한다.
2번 촬영 런처·3번 별도 YOLO와 동시에 켜지 않는다.
ultralytics는 wheelchair_vision console script가 실제 사용하는 Python에 설치되어 있어야 한다. 가상환경 활성화만으로 이미 빌드된 console script의 Python이 바뀌지 않는다. ModuleNotFoundError가 나면 실행 파일의 Python 경로와 설치 환경을 맞춰 다시 빌드한다.
이번에 이 전체 실행을 재현하지 않았으므로 설치·실행 성공이나 거리 정확도·장애물 회피를 완료로 보고하지 않는다.

5. 센서 확인과 거리 검증 기록

실행 중인 환경에서 새 터미널에 ROS와 작업공간을 source한 뒤:

ros2 topic hz /camera
ros2 topic hz /scan
ros2 topic echo /yolo/detected_objects

각 확인은 Ctrl+C로 종료한다. 모든 터미널의 ROS_DOMAIN_ID를 같게 맞춘다.
camera_height_m, camera_pitch_rad, camera_hfov_rad가 실제 사용 모델의 카메라 설정과 맞는지 확인한다. 촬영용과 최신 팀 로봇은 같은 버전이 아니다.
실측·예측값을 새 CSV에 기록한 뒤 저장소 루트에서:

python3 src/wheelchair_vision/tools/evaluate_distance.py /경로/채운_distance_validation.csv

양식: src/wheelchair_vision/distance_validation_template.csv
상세: src/wheelchair_vision/DISTANCE_NOTES.md
빈 양식은 측정 결과가 아니다. BEV·AIR별 실제 거리와 예측값을 채운 뒤 MAE/RMSE를 확인한다.
